⚽ Kickcall Auto Upload

Football score prediction Shorts, generated by a small physics game.

What it does

Kickcall Auto Upload is a personal, non-commercial tool used by a single channel owner. It:

  • lets the owner pick upcoming football matches from a fixture list,
  • generates a short vertical video in which a physics mini-game "plays" the match and produces a score prediction,
  • creates a title, description and cover image for each video, and
  • uploads the video to the owner's own YouTube channel, scheduled to go public before kick-off.

Who uses it

The tool runs locally on the channel owner's own computer. It is not offered to other users and does not access any YouTube account other than the owner's.

YouTube API usage

The tool uses the YouTube Data API v3 only to upload the owner's own videos (youtube.upload) and to display which channel is connected (youtube.readonly). See the Privacy Policy for details.

By using this tool you agree to the YouTube Terms of Service.
