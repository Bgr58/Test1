Privacy Policy

Kickcall Auto Upload · Last updated: 17 November 2026

Summary

Kickcall Auto Upload is a personal tool that runs on its owner's own computer. It does not collect, sell or share personal data, and it has no servers of its own.

Use of YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • OAuth tokens issued by Google after the channel owner grants access. They are used only to call the YouTube Data API.
  • Basic channel information (channel ID and title) via the youtube.readonly scope, only to show which channel is connected.
  • Video uploads via the youtube.upload scope: the tool uploads videos it generated itself, with their title, description, tags, cover image and scheduled publish time.

The tool does not read, modify or delete any other videos, comments, analytics or account data.

How data is stored

OAuth tokens and the tool's settings are stored only in a local folder on the owner's computer. They are never sent to the developer or to any third party. Data is sent only to Google/YouTube when a video is uploaded. Generated videos and their metadata are stored locally until the owner deletes them.

Sharing

No user data is shared with, sold to or transferred to any third party.

Cookies and tracking

The tool and this website do not use advertising or tracking cookies.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page (Third-party apps with account access). Using "Disconnect" in the tool, or deleting its local data folder, removes the stored tokens from the computer.
